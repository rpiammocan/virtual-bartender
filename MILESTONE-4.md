# Milestone 4 — First Usable UI

Implemented:

- Neutral home screen
- My Bar screen
  - API-backed inventory
  - ingredient search
  - manual ingredient creation
  - remove ingredients
- Tonight's Bar screen
  - persistent dated sessions
  - session selector
  - independent session inventory
  - delete with confirmation
- What Can I Make?
  - choose My Bar or a Tonight's Bar session
  - displays Makeable results
  - displays Almost There results
  - surfaces substitutions and optional missing ingredients
- Responsive layout for laptop and smartphone browsers

Not yet implemented in UI:

- Copy My Bar into a Tonight's Bar session
- optional quantities
- recipe detail screen
- shopping list
- favorites/history
- Surprise Me
- URL recipe import
- backup/restore
- printing
