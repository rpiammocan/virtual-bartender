# Built-in Recipe Data

The production built-in recipe library will be curated from open/authoritative references.

Policy:

- Prefer authoritative/open references.
- Do not copy expressive recipe prose verbatim from commercial sites.
- Normalize names, ingredients, quantities, categories, and instructions into Virtual Bartender's own format.
- Store provenance/source metadata for every built-in recipe.
- Images are optional.
- Prefer open/reusable real photos where practical.
- If an AI-generated representative image is used, the image itself must include a small corner label stating that it is AI generated.
- Avoid online API dependency for normal recipe access.
